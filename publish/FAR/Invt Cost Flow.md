- GAAP Methods
	- Specific identification
		- item cost in invt uniquely identified to that item
		- cost follows phys flow in/out invt to COGS
		- physically large/high value items
	- FIFO
		- sell old; unsold new
		- ending invt/cogs same under periodic/perpetual invt sys
		-

		- ![[Pasted image 20260803061322.png]]
	- Weighted Avg
		- follows periodic sys only
		- at period end, avg cost of each inv item is weighted avg of costs of all items in invt
		- weighted avg cost per unit = tot invt costs avail / tot # units avail
		- suitable for homogeneous prod
		- ![[Pasted image 20260803064955.png]]
	- Moving Avg
		- follows perpetual sys only
		- compute weighted avg cost after each purchase
		- moving avg cost per unit = tot invt cost avail after each purchase / tot units avail after each purchase
		- ![[Pasted image 20260803065257.png]]
	- LIFO
		- sell newest; unsold old
		- ending invt, COGS diff under periodic/perpetual sys
		- LIFO conformity rule
			- if used for tax purposes, it shows gov in inflationary env
				- higher COGS
				- reduced taxable income
			- if used for tax, must be used in GAAP FS
		- greater matching of expenses n revenue
			- if sales>purchases for period, LIFO results in distortion of NI bc old invt costs (LIFO layers) matched w current revenue
		- if LIFO in rising price env, and price/unit ↑, ur selling new expensive higher costs, thus lower profit
		- lower profit = lower RE = lower equity = lower A (end invt blnce)
		- ![[Pasted image 20260803070559.png]]
		- ![[Pasted image 20260803070639.png]]
	- Dollar value LIFO
		- invt measured relative to base-yr $ values and adj for changing price lvls using price index
		- price index = end invt at current yr cost / end invt at base yr cost
		- if prices rising, price index >1
